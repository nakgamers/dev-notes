Isinya masalah nyata yang saya temui saat membangun aplikasi Laravel & CodeIgniter 4 di
lingkungan Windows + Laragon, beserta penyebab akar dan solusi yang sudah terbukti jalan.

## Kenapa repo ini ada

Setiap kali saya lupa solusi yang pernah saya temukan, saya kehilangan waktu berjam-jam
mengulang proses debug yang sama. Repo ini adalah memori eksternal saya. Kalau ada yang
ikut terbantu, silakan pakai.
